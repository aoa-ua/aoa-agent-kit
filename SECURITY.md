# Security

Report vulnerabilities in the SDKs, in the AOA API or in the AOA MCP server
privately to security@aoa.com.ua. Please do not open a public issue for them.

If an AOA API key or a webhook secret leaked, write to the same address or
use https://aoa.com.ua/contact: keys are revoked at once, and a webhook secret
is replaced by deleting and re-registering the endpoint.
